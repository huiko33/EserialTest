# EserialTest · Qt 串口调试上位机

基于 Qt 6 / C++17 的串口调试工具，支持串口参数配置、数据收发、文件传输与配置持久化。

## 功能
- 串口枚举与打开/关闭，波特率、数据位、校验位、停止位可配置
- 文本收发，支持 CR / LF / CRLF 行末符（在字节层拼装）
- 文件发送：分块传输 + bytesToWrite() 背压控制，带进度与取消
- 串口参数持久化到 ini，启动自动恢复

## 技术点
- 三层架构：UI / 业务门面 / 通信执行，界面与通信完全解耦
- 通信对象通过 moveToThread 运行在独立工作线程，跨线程仅走队列信号槽
- 接收端使用有状态 QStringDecoder 跨包解码，解决 UTF-8 多字节字符被分包截断的问题

## 构建
- Qt 6.10（MinGW 64-bit）
- 打开 `EserialTest.pro`，qmake 构建即可
